What changed and why

  1. The canvas is the page. No full-height column: every control floats over the 3D view and only what's needed is open.
  2. Top bar = where am I + mode. Project / floor (dropdown with levels, versions), the 3D · Plan · Walk switch in the middle, Share and Edit on the right. In edit mode undo / redo and a "Saved" state show up there.
  3. Left rail = panels, one at a time. Rooms, Saved views, Variants, Comments, Export; in edit mode also Activity and Underlay. Each opens a flyout with its own scroll, so nothing pushes anything else down.
  4. Bottom dock = tools. Icon buttons with their shortcut letter: Select, Draw walls, Room from walls, Railing, Measure, Comment, and one orange Add. The active tool's options (wall type, thickness, height, arc) appear in a bar above the dock instead of inside the panel.
  5. Add is a library, not a <select>. Categories, search and icon tiles; parts that need a selection (doors need a wall, a roof window a roof) are greyed with the reason.
  6. Right inspector only when something is selected. Header with name and type, an icon action row (copy, turn, zoom to, delete), fields in collapsible groups with units inside the inputs, materials as swatches and wall finishes as a band list instead of JSON. In view mode it is a read-only fact card.
  7. Display is one popover (eye, bottom right): icon toggles for what to show, floors, day / night / sun, lens and quality. The wall cut, used constantly, stays visible as a slider.
  8. Floors are a level picker at the bottom left (like indoor maps), with the "floors below" stack toggle.
  9. Help leaves the panel. The long how-to paragraphs become tooltips, a status line with the current tool's hint, and a shortcuts sheet (keyboard icon).
  10. Icons: Lucide (ISC), via lucide-angular or a small inline sprite like this page's.
